============================
Health Tracker - Run Instructions
============================

To run the project locally, use the following commands:

| What      | Command                      | Where to run           |
|-----------|------------------------------|------------------------|
| Backend   | npm run dev                  | Project root           |
| Frontend  | cd client && npm start       | Project root (then client/)


1. Open a terminal in your project root and run the backend:
   npm run dev

2. Open a second terminal, go to the client folder, and run the frontend:
   cd client
   npm start

3. Access the app in your browser at:
   http://localhost:3000

- Backend server runs at: http://localhost:5000
- Frontend React app runs at: http://localhost:3000

If you make changes to backend code or .env, restart the backend server.
